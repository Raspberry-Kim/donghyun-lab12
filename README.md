# 동현심 v0.03

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24050245.svg)](https://doi.org/10.5281/zenodo.24050245)

강이 흐르는 평지 하나에 길과 전선을 깔고 주거·상업·공업 구역을 놓아 작은 도시를 키우는 놀이다. 전기와 길이 닿은 구역은 수요에 따라 자라고, 달마다 세금이 들어오고 유지비가 나간다. **시작 자금**과 **이벤트·재해 켬/끔**을 동현랭으로 정한다.
동현 시리즈의 열두 번째 작은 실험이다. 마우스와 손가락만으로 논다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab12/

## 놀이 방법

- 처음 열면 판 위에 **새 도시 시작** 단추가 떠 있고 달은 멎어 있다. 저장한 도시가 있으면 동현랭 코드 아래 **저장한 판 불러오기**에 칸이 보인다. 오른쪽 동현랭 코드의 시작을 누르면 그 설정으로 새 도시가 바로 시작된다.
- 판 아래 **도구** 열둘 가운데 하나를 고른 뒤 판을 누른다. 길(10냥)·전선(5냥)·공원(30냥)·철거(1냥)는 누른 채 끌면 지나간 칸에 이어진다. 주거·상업·공업 구역(각 100냥)과 발전소(3,000냥)·경찰서·소방서(각 500냥)는 3×3이라 누르면 초록 테두리가 따라오고 손을 떼는 자리에 놓인다. 빨간 테두리면 놓을 수 없다. 강 위의 길은 다리(50냥), 강 위의 전선은 25냥이다.
- **이동** 도구로 판을 끌면 보는 자리가 옮겨진다. 어떤 도구를 쥐고 있어도 두 손가락으로 끌면 옮겨지고 벌리면 커진다. 마우스는 바퀴로 늘리고 줄이며 가운데·오른 단추로 끌면 옮겨진다. 판 오른쪽 아래 +·−·⤢ 단추도 같다.
- **정보** 도구로 칸을 누르면 그 칸이 무엇인지, 전기·길·지가·오염·치안이 어떤지 말해 준다. 판 왼쪽 위 **보기** 단추로 전력·오염·범죄·지가를 색으로 겹쳐 본다.
- 위의 멈춤·보통·빠름·아주 빠름 단추로 달이 흐르는 빠르기를 바꾼다. 다른 탭을 보거나 창을 벗어나면 저절로 멎는다.

## 도시가 자라는 법

- 구역은 **전기**(전선이나 전기 있는 이웃 구역·건물에 닿기)와 **길**(3×3 둘레에 길 한 칸)이 모두 있어야 자란다. 둘 중 하나가 빠지면 번개·회색 길 표시가 뜨고 천천히 줄어든다.
- 주거·상업·공업 수요는 서로를 당긴다. 사람이 늘면 가게와 일자리가 필요하고, 일자리가 있으면 사람이 온다. 구역은 1~5단계까지 자라고 주거 1단계가 160명이다.
- 공장은 오염을 내고 오염이 높으면 지가가 내려 집이 잘 자라지 않는다. 강·나무·공원은 지가를 올린다. 사람이 늘면 범죄가 늘고 경찰서가 둘레의 범죄를 누른다. 소방서는 불이 번지는 것을 막고 빨리 끈다.
- 달마다 자란 구역 단계만큼 세금이 들어오고(주거·공업 10냥, 상업 12냥) 발전소 40냥, 경찰서·소방서 30냥, 길·전선·공원 칸마다 조금씩 유지비가 나간다. 돈이 바닥나면 지을 수 없다.
- 인구에 따라 칭호가 바뀐다: 촌락 → 마을 500 → 읍 2,000 → 도시 10,000 → 대도시 30,000 → 수도 60,000.
- **이벤트**(켜 두었다면, 달마다 1/30): 포동이 시장의 축제, 슈슈의 기부금, 관광객(세금 두 배), 초파리 떼의 나무 심기. **재해**(켜 두었다면, 3년차부터 달마다 1/60): 불, 강의 범람, 도시를 가로지르는 거대 라이언(일곱 달쯤 머문다). 부서진 자리는 철거하면 다시 쓸 수 있다.

## 저장과 불러오기

- 동현전·동현워·동현몬과 같은 방식이다. 판 아래 **저장**을 누르면 메뉴가 뜨고, **브라우저 칸 1·2·3** 가운데 하나에 남기거나 **파일로 내려받기**로 `.dhsave` 파일 하나로 내려받는다. 찬 칸은 덮어쓸지 한 번 더 묻는다. 저절로 저장되지는 않는다.
- **불러오기** 메뉴에서 칸을 고르면 그 도시가 되살아나고(저장하지 않은 달은 사라지니 한 번 더 묻는다), **파일에서 불러오기**로 `.dhsave` 파일을 고를 수도 있다. 파일 속 설정(자금·이벤트·재해)도 함께 따라온다. 메뉴가 열린 동안 달은 멎는다.
- 처음 화면에서는 동현랭 코드 아래 **저장한 판 불러오기**에 칸 세 개가 보인다. 찬 칸을 누르면 바로 이어지고, **지우기**는 두 번 눌러야 비워진다. 칸은 이 기기의 이 브라우저에만 남는다(사이트 데이터를 지우거나 사생활 보호 창을 닫으면 사라지고, Safari는 7일 동안 열지 않으면 지울 수 있다).

## 동현심 규약

동현랭 코드가 출력한 **정수 셋**이 자금 옵션 · 이벤트 · 재해다.

| 자리 | 뜻 | 값 |
| --- | --- | --- |
| 첫째 | 자금 옵션 | `0` 넉넉하게 50,000냥 · `1` 보통 20,000냥 · `2` 빠듯하게 10,000냥 · `3` 아주 넉넉하게 100,000냥 |
| 둘째 | 이벤트 | `0` 끔 · `1` 켬 |
| 셋째 | 재해 | `0` 끔 · `1` 켬 |

- 기본값은 `1 1 1`이다. 아무것도 출력하지 않으면 이 값으로 시작한다.
- 셋이 아닌 개수로 출력하거나 범위를 벗어나면 시작하지 않고 오류를 알려 준다.
- 코드는 새 도시를 시작할 때만 읽는다. 이어 하는 도시는 저장될 때의 설정을 그대로 쓴다.
- 예제 여섯: **01 기본 모드**(1 1 1), **02 자금 옵션**(0 1 1 · 50,000냥), **03 이벤트 끄기**(1 0 1), **04 재해 끄기**(1 1 0), **05 자금 옵션 100,000냥**(3 1 1), **06 모래 놀이판**(3 0 0 · 100,000냥에 이벤트·재해 끔). 동현랭 코드는 길을 깔거나 구역을 놓지 않는다. 지도는 하나로 정해져 있고 어디에 무엇을 놓을지는 사람이 손으로 한다.

```
나는 동현이냐?
ㅋㅋ 자금 옵션 0 · 넉넉하게 50,000냥
뿡뿡 도옹ㅠ~뿡뿡뿡
ㅋㅋ 이벤트 켬
뿡뿡 도옹~뿡뿡뿡
ㅋㅋ 재해 켬
뿡뿡 도옹~뿡뿡뿡
동현이구나
```

## 조작

- **마우스·터치만** 쓴다. 키보드와 게임패드는 판을 움직이지 않는다. 머리글의 입력 표식도 마우스(터치)·전체 화면만 켜져 있다. 키보드는 동현랭 코드를 쓸 때만 쓴다(⌘/Ctrl+Enter는 코드 실행).
- **전체 화면**: 판 위 오른쪽의 네모 단추. 휴대폰은 가로로 돌려도 좋다. 닫기는 왼쪽 위 ✕.
- 휴대폰은 두 번 두드려도 확대되지 않고 판에서 손가락을 끌어도 화면이 밀리지 않는다(동현텐의 휴대폰 경험). 손가락으로 길·전선을 누르면 떼거나 움직이기 시작할 때 놓이므로, 두 번째 손가락이 바로 따라오면(두 손가락 옮기기·늘리기) 아무것도 놓이지 않는다.

## 그림과 얼굴

타일과 건물 그림 서른아홉(풀·물·나무·공원·잔해·불·연기, 주거·상업·공업 1~5단계, 발전소·경찰서·소방서, 도구 아이콘 열)은 `tools/tiles.py`가 글자 격자로 새로 그렸다(`src/tiles.js`). 소식에 나오는 포동이 시장·슈슈·라이언·초파리·둠가이 얼굴은 동현주의 16×16 그림(`src/sprites.js`)을 그대로 쓴다. 원작 게임의 그림은 한 점도 쓰지 않았다.

## 효과음

소리 파일 없이 브라우저 안에서 합성한다(Web Audio). 도구를 고르면 톡, 길·전선을 깔면 짧은 탁, 구역·건물을 놓으면 둥, 발전소는 낮은 둥, 철거는 바스락, 해마다 결산과 기부·저장은 짤랑, 소식은 띵, 좋은 소식과 칭호는 올라가는 음, 불은 경보, 범람과 괴수는 우르릉, 놓을 수 없으면 낮은 부저가 난다. 머리말의 스피커 단추로 켜고 끈다.

## 원작에 관하여

Nintendo DS판 「SimCity DS」(2007, 개발 AKI Corporation·EA Japan, 발매 Electronic Arts)에서 따온 도시 만들기의 뼈대를 따른다. SimCity DS는 「SimCity 3000」을 바탕으로 터치 펜으로 길·전선·구역을 놓도록 고친 작품이다. 동현심은 그 뼈대만 아주 작게 만들었고(지도 하나, 구역 셋, 건물 넷), 원작의 코드·그림·소리·글·지도를 쓰지 않았으며, 제작사·발매사와 관계가 없다. 구체적인 수치는 모두 동현심이 정한 것이다. 자세한 내용은 [CREDITS.md](CREDITS.md).
